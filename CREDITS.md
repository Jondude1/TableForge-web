# Credits

TableForge's look was put together from D&D / TTRPG interface designs found through Pinterest's
"DnD UI" and "DnD app" boards. Pinterest pins point back to the original makers, so these are
credited at the source. No artwork, code or assets were copied from these projects — they shaped
the palette, type choices and a few interaction patterns, which are reimplemented from scratch.

## Design inspiration

## Icons and libraries

- Interface icons are simple stroke icons drawn for TableForge, following Material Symbols geometry (Google, Apache License 2.0).
- Map tokens use the device's system emoji font.
- Built with React, Vite and Dexie (IndexedDB). Sync uses nostr-tools and public Nostr relays (relay.damus.io, nos.lol, relay.primal.net, nostr.mom, offchain.pub) — thanks to the people who run them.
